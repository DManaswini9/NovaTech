# 🛒 NovaTech – E-Commerce Website

NovaTech is a fully responsive multi-page E-Commerce website built using HTML, CSS, and JavaScript.

## ✨ Features

- Interactive Hero Slider
- Dynamic Product Rendering using JavaScript
- Product Listing Page
- Product Detail Page
- Responsive Grid Layout
- Category & Filter Section
- Clean and Modern UI Design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript 
- Responsive Grid System
